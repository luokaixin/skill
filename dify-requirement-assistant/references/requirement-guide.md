# 需求沟通引导问卷

本文档定义了需求沟通阶段的结构化问题清单。不要一次性提出所有问题，应根据用户回答动态选择后续问题，每次提问 2-3 个。

## 沟通原则

1. **渐进式提问**：每次 2-3 个问题，等用户回答后再问下一批
2. **提供选项**：每个问题给出 2-4 个选项，降低回答门槛
3. **追问细节**：用户回答模糊时，用具体例子追问
4. **确认理解**：每个维度问完后，简要复述确认理解是否正确
5. **引导思考**：用户没考虑到的维度，主动提出并给出建议
