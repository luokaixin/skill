# 视觉规范

一张图的专业感，八成来自**间距、字号、颜色的一致性**，不是来自图形本身多花哨。
本文给出可直接套用的 token 与版式规则。

## 一、两套配色体系

### 1.1 默认：办公分析风

适合数据表、方法论模型、汇报类图示。特征是**蓝表头 + 深色分区标 + 白底斑马表**。

| Token | 值 | 用途 |
| --- | --- | --- |
| 主色 | `#3370FF` | 主标题胶囊、表头填充 |
| 表头字 | `#FFFFFF` | 表头行 |
| 深色区块 | `#262D3D` | 分区标题底、强调圆 |
| 深色区块字 | `#FFFFFF` | 深色底上的文字 |
| 正文 | `#1F2329` | 标题、正文、表内文字 |
| 辅助文字 | `#646A73` | 导语、说明、日期 |
| 表格线 | `#D7D9DD` / `#E5E6E8` | 表格分隔 |
| 斑马行 | `#F5F5F5` | 表格奇偶行 |
| 卡片底 | `#FFFFFF` | 模块外框内 |
| 外框描边 | `#DEE0E3` | 整体浅灰边界 |
| 辅线 | `#8F959E` | 花括号、示意图连线 |

### 1.2 柔和色（需要更轻的观感时）

适合流程图、架构图、时间线这类以图形为主的图。

| Token | 值 |
| --- | --- |
| 正文主色 | `#1F2329` |
| 正文辅色 | `#646A73` |
| 描边 | `#1F2329`（1.5px） |
| 浅边框 | `#DEE0E3` / `#C9CDD4` |
| 引导线 | `#8F959E`（1px） |
| 卡片圆角 | `rx 8` |
| 外框圆角 | `rx 12` |

填充色（同一图内不超过 5 种，同色系深浅搭配）：

| 色系 | 浅底 | 深字 |
| --- | --- | --- |
| 蓝 | `#D6EBFF` | `#2A5F94` |
| 紫 | `#E5D4FA` | `#6C4CC4` |
| 绿 | `#D5F2E0` | `#2F6B3E` |
| 黄 | `#F9EDBE` | `#8A6A12` |
| 粉 | `#FAD9E6` | `#9C4157` |
| 橙 | `#FDE3CC` | `#A0522D` |
| 灰 | `#EDEEF0` | `#5A6169` |

**规则**：填充用浅色，文字用同色系的深色。不要浅底配黑字（对比过硬），
也不要深底配浅字做大面积区块（视觉过重）。

## 二、字号

**只允许 12 / 14 / 16 / 18 / 20 及更大的标题字号。**

| 用途 | 字号 | 字重 |
| --- | --- | --- |
| 页面标题 | 20 | bold |
| 分区 / 模块标题 | 16–18 | bold |
| 卡片标题 | 16 | bold |
| 正文、表格单元格 | 14 | normal |
| 图例、角标、密集次要列 | 12 | normal |

禁止 9 / 10 / 11 / 13 / 15 / 17 / 19。

12px 使用面积占比不超过约 20%。内容放不下时，优先放大画布或拆分布局，
不要靠缩字号硬塞。

## 三、间距

| 项目 | 建议值 |
| --- | --- |
| 画布左边距 | 140 |
| 标题到副标题 | 48 |
| 标题区到内容区 | 70–90 |
| 卡片内边距 | 12–16 |
| 卡片之间的间隙 | 16–24（紧凑布局 4–8） |
| 表格行高 | 40–46 |
| 表格表头高 | 44–48 |
| 段落行高 | 字号 × 1.5 |

**间隙要一致。** 同一张图里出现 12 / 16 / 24 三种间隙而无明确层级理由，
视觉上就是「没对齐」。

## 四、圆角

| 元素 | 圆角 |
| --- | --- |
| 卡片 | 8 |
| 外框 / 分区 | 12–16 |
| 小色块、图例方块 | 3–4 |
| 胶囊 / 全圆角 | 用 `shape-full-rounded-rect` |
| 直角容器 | `rx: 0` |

**注意**：全圆角必须用 `shape-full-rounded-rect`，不能用 `rx = 高度/2` 模拟。
`rx` 会被渲染时裁剪，退化成普通圆角矩形，而 JSON 上看不出问题。

## 五、层级（zIndex）

| 层级 | 内容 |
| --- | --- |
| 0–1 | 分区底、虚线轴、浅底外框、隐形锚点 |
| 2 | 普通连接线 |
| 3–4 | 卡片底框、色条、图形主体 |
| 5 | 轴点、箭头笔划 |
| 6+ | 文本节点（最上层，便于点选） |

组盒必须低于其成员，否则会遮住子节点。

## 六、留白与密度

| 图的类型 | 建议密度 |
| --- | --- |
| 汇报 / 展示 | 疏：卡片少、留白多、字号偏大 |
| 模板 / 结构图 | 中：信息完整，间距统一 |
| 明细表 | 密：行高收紧，但字号不低于 12 |

判断标准：把图缩小到 50% 看，如果还能分清层级，密度就是合适的。

## 七、常见视觉问题

| 现象 | 原因 | 修复 |
| --- | --- | --- |
| 整体看着「散」 | 间隙不一致，或元素未对齐基线 | 统一 gap；同类元素左边缘或中心线对齐 |
| 层级不分 | 所有文字同一字号 | 标题 16–18 bold，正文 14，辅助 12 |
| 颜色花 | 填充色超过 5 种 | 收敛到 4–5 个色系，其余用灰 |
| 文字挤 | 节点宽度不足 | 加宽节点或拆分文本，不要缩字号 |
| 视觉重心偏 | 内容未在画布居中 | 计算整体包围盒，再统一平移 |
| 深色区块太重 | 大面积深底浅字 | 深色只用于小面积标签 |
| 描边过粗 | 所有图形统一用 2px | 卡片 1–1.5px，强调元素才用 2px |

## 八、配色速查

需要快速给一组分类上色时，按这个顺序取（同一图内前 N 个）：

```
1  蓝  #D6EBFF / #2A5F94
2  紫  #E5D4FA / #6C4CC4
3  绿  #D5F2E0 / #2F6B3E
4  黄  #F9EDBE / #8A6A12
5  粉  #FAD9E6 / #9C4157
6  橙  #FDE3CC / #A0522D
```

超过 6 类时，第 7 类起改用中性灰 `#EDEEF0 / #5A6169`，
或用同色系的不同深浅（如蓝的 `#D6EBFF` 与 `#B8D9F5`）区分。
